# Заметки Арта

Расширение Chrome: боковая панель заметок через встроенный **Side Panel**. Расширение **не получает доступ к сайтам** — не читает и не изменяет страницы. Chrome сам уменьшает область вкладки, когда панель открыта.

**Версия:** 1.2.0  
**Требования:** Google Chrome 114+

Официальный репозиторий: [github.com/artbashlykov/art-chrome-notes](https://github.com/artbashlykov/art-chrome-notes)

## Установка (режим разработчика)

1. Откройте `chrome://extensions/`
2. Включите **Режим разработчика**
3. **Загрузить распакованное расширение** → папка проекта
4. Откройте любой сайт → клик по иконке расширения или **Alt+S**

Повторный клик по иконке закрывает панель (встроенное поведение Chrome).

## Использование

| Действие | Как |
|----------|-----|
| Открыть / закрыть | Иконка расширения (переключатель) |
| Горячая клавиша | `Alt+S` — открыть панель |
| Закрепить | Булавка — при смене вкладки панель снова открывается |
| Закрыть | ✕ в заголовке панели |
| Заметки | Только локально в `chrome.storage` |

## Разрешения

| Permission | Зачем |
|------------|--------|
| `sidePanel` | Показать панель справа в UI браузера |
| `storage` | Сохранить заметки и настройки |

**Нет** `host_permissions`, **нет** content scripts — доступ ко всем URL не запрашивается.

## Структура

```
manifest.json
background.js
sidepanel/
  sidepanel.html
  sidepanel.css
  sidepanel.js
icons/
```

## Публикация в Chrome Web Store

Такой вариант проще проходит модерацию: не нужно обосновывать `<all_urls>` и доступ к содержимому страниц.

## Отличие от прежней версии

Раньше панель внедрялась в страницу (content script). Сейчас это отдельная панель Chrome — визуально похоже (сайт сдвигается влево), но технически безопаснее для пользователя и проще для публикации.
